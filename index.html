🎓 AI 面試官

上傳自傳、選擇科系，來一場模擬面試

1你的資料

上傳自傳、研究方向、讀書計畫等（.txt / .pdf），或直接貼上文字。資料只會送給你設定的 AI 服務。

📄 點這裡選擇檔案，或把檔案拖進來

    2面試目標

    學校和科系可以從清單選，也可以自己輸入。

    3參考題庫

    勾選你想被問到的題目，AI 會挑選並結合你的資料改寫。

    ℹ️ 內建題庫是常見題型歸納，並非特定學校的官方題目。按下方「上網搜尋歷屆面試題」，AI 會用 Google 搜尋 Dcard、PTT 等考生心得整理出歷屆題並附上來源；你也可以自己加入看到的題目。

    API 設定

    預設使用免費 AI，不需金鑰。若想更穩定，可改用自己的金鑰；金鑰只存在你這台電腦的瀏覽器裡，不會上傳到 GitHub 或其他地方。
