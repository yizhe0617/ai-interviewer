# Cloudflare 中繼站部署步驟

## 1. 申請 Gemini 金鑰
1. 到 https://aistudio.google.com/apikey 用 Google 帳號登入。
2. 按「Create API key」，複製金鑰（先存在記事本，**不要貼到任何網頁原始碼或 GitHub**）。

## 2. 建立 Cloudflare Worker
1. 到 https://dash.cloudflare.com/sign-up 註冊並登入（免費方案即可）。
2. 左側選單 **Workers & Pages** → **Create** → **Create Worker**（選 Hello World 範本）。
3. 名稱填 `ai-interviewer`，按 **Deploy**。
4. 部署完按 **Edit code**，把編輯器裡原本的程式全部刪掉，貼上 `cloudflare-worker/worker.js` 的全部內容，按右上 **Deploy**。

## 3. 設定金鑰與允許的網址
1. 回到這個 Worker 的頁面 → **Settings** → **Variables and Secrets** → **Add**。
2. 新增第一個：
   - Type：**Secret**
   - Name：`GEMINI_API_KEY`
   - Value：貼上你的 Gemini 金鑰
3. 新增第二個：
   - Type：**Text**
   - Name：`ALLOWED_ORIGINS`
   - Value：`https://你的GitHub帳號.github.io,null`
     （`null` 是讓你在自己電腦雙擊開 index.html 測試時也能用；上線後想更嚴格可以拿掉）
4. 按 **Deploy** 儲存。

## 4. 把網址給 Claude
Worker 頁面上方會顯示網址，長得像 `https://ai-interviewer.你的名稱.workers.dev`。
用瀏覽器打開它，看到 `{"ok":true,...}` 就代表成功。把這個網址貼回對話，Claude 會把它填進 index.html 的 `RELAY_URL`。

> 網址本身不是祕密，放在公開網頁沒關係；真正的金鑰只存在 Cloudflare。
